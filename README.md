# UTN Final Project — Bookstore API

REST API for a small online bookstore, built with Node.js, Express and MongoDB (Mongoose).
Final project of the UTN Backend Developer course.

## Domain

Customers browse books and place orders; admins manage categories, books and stock.

## Data model

Four collections: `usuarios`, `categorias`, `productos` and `pedidos`.
